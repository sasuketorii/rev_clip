2026-09-17にユーザーが提供した日本語元データを保存しています。空行と末尾の空列を除き、UTF-8 CSVに変換しました。会社・人物・連絡先・成果数値は提供されたDemo用の内容であり、実在性や事業実績を検証した資料ではありません。メールは送信していません。

## メールのルール

既存の英語Demoを確認し、次の形式へ揃えました。

- タイトル: `[種別] 用途`。
- 本文: 件名、空行、メール本文の順。`件名:` という追加ラベルは付けない。
- 差し替えタグ: `{{会社名}}` のような二重波括弧。日本語のタグ名を使用する。
- 資料・月次レポート・申込先などのURLは用途別の差し替えタグとする。署名内の会社URLは固定。
- 問い合わせ返信とフォローアップのサービス名、キックオフの媒体名も、英語版と同様に差し替え式とする。
- `差替タグ一覧` は実際の件名・本文から再生成し、未使用タグを載せない。

差し替えタグは保存されるテンプレート文字列です。この作業で自動置換機能を新設したものではありません。

## 再生成

リポジトリのルートで次を実行します。Pythonの標準ライブラリだけを使用します。

```sh
python3 assets/demo/ja/build.py
```

これはCSVから登録用データを生成するだけで、アプリのデータを変更しません。アプリへの登録はRevclipのテンプレートCLIで、対象を `--app revclip-demo` と明示して行います。同名項目が存在する場合は先に内容を照合し、重複登録や無断上書きを避けてください。
