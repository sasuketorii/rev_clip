**⌘⇧Vで、履歴も、定型文も、設定も。** RevclipはmacOSのメニューバーに常駐する、ローカル保存型のクリップボードマネージャーです。コピー履歴、文章・画像テンプレート、ホバープレビューをひとつのメニューから利用できます。

エージェントと一緒に使うクリップボードとして、定型文・プロンプト・画像テンプレートの作成・編集・削除をエージェントへ依頼できます。Revclip CLIにはコピー履歴を読み出すコマンドがありません。これはCLIの機能範囲であり、OSの権限を持つエージェントからの完全な隔離を保証するものではありません。

このREADMEは **v0.2.2（build 60、2026年9月18日時点）の実装** を説明します。画面の文字をコピーする **faster OCR**、権限ステータス、OCRを含む44項目の設定CLIを追加しています。ベトナム語を含む9言語に対応します。公開済みのバージョンと配布物は[Releases](https://github.com/sasuketorii/rev_clip/releases)で確認してください。

実装・実機・性能・配布の確認範囲は[faster OCRの検証状況](docs/REV_OCR.md)と[品質検証報告](docs/QUALITY_REPORT.md)に記録しています。ローカル候補の導入と公開配信を取り違えないよう、[リリース完了判定](docs/RELEASING.md#完了判定ローカル更新と公開配信を分ける)でタグ・公開DMG・更新フィードを照合します。

| 機能 | 現在の動作 |
| --- | --- |
| コピー履歴 | 文章、書式付きテキスト、HTML、画像、PDF、ファイル参照、URLを記録し、後から選んで復元 |
| faster OCR | **⌘⇧2 → 文字を囲む → コピー**。Apple Visionによる端末内の文字認識 |
| 権限ステータス | アクセシビリティ・クリップボード・画面収録の状態と設定への入口 |
| テンプレート | フォルダで分類した定型文・プロンプト・画像を保存。専用エディタとCLIから編集 |

| メニュー | 履歴を件数ごとのサブメニューに整理。表示数、タイトル、画像、アイコンなどを調整 |
| 外観 | システム連動・ライト・ダーク。メニュー専用の色設定とHEX入力 |
| 保存時の暗号化 | SQLCipherでデータベース、AES-256-GCMでクリップ本体・サムネイルを保護 |
| 自動整理 | 最大件数・保存期限による履歴削除。手動消去にも対応 |
| 多言語 | 日本語を含む9言語。設定から切り替え |
| 更新 | 通常版はSparkleによる更新確認・配布版への更新 |
| エージェント連携 | 同梱スキルの登録、テンプレート操作、OCR・ショートカットを含む44項目の設定CLI |
| バグ報告 | GUI・CLIから明示的な同意付きで送信。履歴の自動添付なし |
| 開発・撮影 | 同じ機能実装から、データ領域を分離したDemo版を生成 |

開発版のリンク取得は既定で自動です。「プライバシー → リンク」で取得方法を選べます。細かな設定は「高度な設定」の上タブにまとめています。

アカウント登録は不要です。履歴・テンプレートのクラウド同期はありません。**更新確認・ダウンロード、URL単体のリンクプレビュー／ファビコン取得、ユーザーが同意して実行するバグ報告ではネットワークを使用します。**

## はじめる

### 配布アプリをインストール

1. [最新版のRelease](https://github.com/sasuketorii/rev_clip/releases/latest)からDMGをダウンロードします。
2. DMGを開き、RevclipをMacの「アプリケーション」フォルダへコピーします。
3. Revclipを起動します。
4. 普段どおり文章をコピーし、**⌘⇧V**で履歴を開きます。
5. 自動貼り付けを使う場合は、macOSの「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でRevclipを許可します。

| 項目 | 条件 |
| --- | --- |
| OS | macOS 14以降 |
| CPU | Apple Silicon / Intel。公開DMGはUniversalアプリ |
| インストール時の開発環境 | 不要 |
| 配布物 | Developer ID署名・Apple公証済みDMG |
| 自動貼り付け | アクセシビリティ権限が必要 |
| faster OCR | 画面収録の許可が必要。初回利用時に案内 |

### アップデート

「設定 → アップデート」から手動確認や自動確認の設定を行えます。通常版の更新フィードは、GitHubの最新Releaseに添付する署名付き `appcast.xml` です。

Demo版には通常版の更新フィードを設定していません。通常版のアップデートでDemo版が置き換わることを防ぐため、Demo版はビルドして更新します。

## 基本操作

| 操作 | 既定の入口・動作 |
| --- | --- |
| メインメニューを開く | **⌘⇧V**。履歴・テンプレート・アプリ操作を表示 |
| 履歴メニューを開く | **⌘⌃V**。テンプレートを含まない履歴とアプリ操作 |
| アプリケーションから開く | Revclipを開くとメインメニューを表示。設定などのウィンドウが開いている場合は、そのウィンドウを前面へ表示 |
| 画面の文字をコピー | **⌘⇧2**、またはメニューの「画面の文字をコピー…」 |
| 入力欄から開く | macOS Services対応の入力欄では右クリックの「Revclip」（「サービス」内の場合あり）。履歴・テンプレートから選んだ文字を返す |
| アイコンから開く | メニューバーのRevclipアイコン |
| 項目の内容を見る | 項目にポインタを合わせてホバー |
| 項目を使う | 選択してクリップボードへ復元。自動ペーストが有効なら元のアプリへ貼り付け |
| 定型文を編集 | メニューの「テンプレートを編集…」 |
| ショートカットを変える | 「設定 → ショートカット」 |

スクリプトからメニューを出さずに起動する場合は、`open -g path/to/Revclip.app --args -suppressLaunchMenu YES` を使用します。初回起動では `open -g` だけと通常の起動を区別できないため、抑止オプションも指定してください。

自動ペーストを使わない場合は「設定 → 一般」のペーストコマンドを無効にします。項目を選んだ後、貼り付け先で通常の **⌘V** を使用できます。

## faster OCR

**⌘⇧2 → 文字を囲む → コピー完了。** 画像・動画・PDFなど、画面に表示された文字をプレーンテキストとしてコピーします。貼り付け先で **⌘V** を押して使います。自動貼り付けは行いません。

- **EscまたはBackspace（Delete）で取消**。右クリックでも取り消せます。
- 選択枠と十字カーソルは、設定したプライマリカラーを使います。未設定時は `#007FFF`。選択範囲の塗りは不透明度10%（透過率90%）で固定です。
- 「設定 → faster OCR」で、有効／無効・ショートカット・認識言語・文章の言語補正・履歴保存を変更できます。メニューには現在のショートカットを表示します。
- 「設定 → 権限ステータス」で画面収録などの許可を確認し、macOSの設定画面へ移動できます。ページを開くだけでは権限を要求しません。

範囲選択にAppKit、画面取得にScreenCaptureKit、文字認識にApple Visionを使います。macOS 14以降が対象です。このmacOSや選択した認識言語が利用できない場合は、有効化時に理由を表示します。使っていない間は、OCRのための画面取得・認識・ウォームアップを行いません。

取得した画像は保存・送信しません。コピーした文字はOSのクリップボードに残ります。履歴保存が有効で、Revclipのクリップボードの許可が「常に許可」の場合に限り、既存の保存・除外・暗号化ルールに従って履歴へ保存します。それ以外はコピーのみです。結果には一時マーカー（`org.nspasteboard.TransientType`）を付けるため、この規約に従う他のクリップボード管理アプリは記録しません。これは他のアプリからの読み取りを防ぐ機能ではありません。

処理中に別のコピーや取消を検出した場合は、古い認識結果を破棄します。Clear・Panic・終了後も古い結果を反映しないようにしています。ただし、OSのクリップボードには他のアプリとの原子的な比較・書き込みの仕組みがなく、書き込み直前の微小な競合を完全に排除する保証はありません。

認識精度は文字の大きさ・画質・配置に左右されます。箇条書きの記号と本文など、同じ行の認識断片を位置に基づいて結合しますが、段落全体の自動整形は行いません。縦書き・複雑な段組み・手書きは保証対象外です。

ショートカットの設定時は、Revclip内の重複、macOSの有効なショートカットとの重複、登録失敗を区別して案内します。他のアプリとの重複や、そのアプリ名は検出できません。同じキーで両方が反応する場合は、どちらかの割り当てを変更してください。

対応範囲・検証状況は[faster OCR](docs/REV_OCR.md)、実装上の注意点は[開発ドキュメント](docs/FASTER_OCR_DEVELOPMENT.md)を参照してください。「RevOCR」は開発中の旧称です。

## コピー履歴と保存形式

### 記録する種類

「設定 → 種類」で、保存対象を選択できます。

| 種類 | 用途・注意点 |
| --- | --- |
| プレーンテキスト | 書式のない文章、コード、プロンプトなど |
| リッチテキスト（RTF） | フォントや装飾を含む文章 |
| 添付付きリッチテキスト（RTFD） | 添付を含むリッチテキスト |
| HTML | Webやデザインアプリがコピー時に提供する書式・構造情報 |
| PDF | クリップボードに提供されたPDFデータ |
| ファイル名 | コピーされたファイルへの参照。ファイルそのもののバックアップとは異なります |
| URL | クリップボード上のURL形式 |
| 画像（TIFF） | コピーされた画像データ |

コピー元は、同じコピーに複数の表現を提供することがあります。Revclipは単に表示用の文字列だけを保存する構成ではなく、クリップボードの形式情報を保存・復元します。

Figmaなどの複数選択や書式付きコピーは、コピー元と貼り付け先が提供・受理する形式にも依存します。別のコピーを挟んで履歴から戻す操作に対応していますが、すべてのアプリ固有形式、遅延提供データ、外部リソースの復元を保証するものではありません。

### 件数と並び順

- 履歴の最大保存数は既定で30件です。
- メニューでは既定で10件ずつのサブメニューにまとめます。
- 保存件数と、メニューに一度に表示する件数は別の設定です。
- 貼り付け後の並び替えや、同じ内容をコピーした場合の扱いは「一般」で調整できます。
- 保存期限を有効にすると、期限を過ぎた履歴も整理対象になります。

新しいコピーで保存件数の上限を超えると、古い履歴から超過分のDB行と対応ファイルを削除します。古さは履歴の更新順に基づき、再コピーや貼り付け後の並び替え設定で変わることがあります。表示だけを隠す処理ではありません。ただし整理は非同期のため、コピー直後に一時的に上限を超えることがあります。詳しくは[保存・削除・プライバシー](#保存削除プライバシー)をご覧ください。

#### 0.1.7の並び順

0.1.7から、再コピーと履歴の利用を分けて扱います。

| 同一履歴を上書き | ペースト後に並び替え | 同じ内容を外部で再コピー | 履歴を選んで復元 |
| --- | --- | --- | --- |
| OFF | OFF | 順序を維持 | 順序を維持 |
| ON | OFF | 最新位置へ | 順序を維持 |
| OFF | ON | 順序を維持 | 最新位置へ |
| ON | ON | 最新位置へ | 最新位置へ |

履歴の利用は、クリップボードへの復元成功時に記録します。自動ペーストOFFでも対象です。その後に対象変更などでキー送信がキャンセルされても、復元成功は取り消しません。復元書き込みに失敗した場合は更新しません。テンプレートの利用は履歴項目の利用に数えません。

同じミリ秒の操作や時計の巻き戻りでも最後の利用順を保つため、保存する更新日時は既存の最大値より少なくとも1ms先に進みます。時計を大きく戻すと、保存期限による削除が実時間より遅れる場合があります。件数による保持順は最後の更新順です。

監視の既定間隔は500msのままです。観測前に上書きされたコピーをすべて回収する保証はありません。改善の比較結果と実機未確認事項は[品質検証報告](docs/QUALITY_REPORT.md)を参照してください。

## テンプレート

### 文章と画像を保存

専用エディタでフォルダとテンプレートを作り、名前・本文・表示状態を編集できます。メール、プロンプト、連絡先、URL、画像など、繰り返し使う内容を整理できます。

- 編集内容は項目切り替え時やエディタを閉じる際に保存します。**⌘S**でも保存できます。
- 画像テンプレートは画像データを埋め込みます。登録後に元画像を移動しても利用できます。
- 非表示にした項目は、内容を削除せずメニューから外せます。
- テンプレート本文はユーザーのデータです。アプリの言語を変更しても本文を翻訳しません。
- `{{Company_Name}}` などを本文に記載できますが、それだけで顧客情報への自動差し込みが実行されるわけではありません。

### インポートとエクスポート

XML plist形式のテンプレートをインポート・エクスポートできます。Clipy互換のテンプレート形式を扱い、インポート時には統合・置き換えを選べます。現行エディタのエクスポートは全フォルダ・全テンプレートが対象で、非表示の項目も含みます。

エクスポートファイルには本文が含まれます。アプリ内の保存暗号化は、外へ書き出したファイルには適用されません。

| 読み込み時の制限 | 上限 |
| --- | --- |
| インポートファイル | 50 MiB |
| フォルダ | 100 |
| テンプレート | 10,000 |
| タイトル | 500文字 |
| テキスト本文 | 1 MiB |
| 画像テンプレート | 10 MiB、単一フレーム |
| 画像の寸法 | 各辺8,192 px以下、合計16,000,000画素以下 |

画像はmacOSのImageIOでデコードできることも条件です。拡張子だけで対応を判断せず、実データを検証します。複数フレーム・アニメーション画像は画像テンプレートの対象外です。

## ホバープレビュー

### 文章

項目の内容をテキストとして表示します。**文章の途中にURLが入っていても、リンクカードへ置き換えません。** プロンプトやメールの全文を確認する用途を優先します。

### 画像

メニュー内では小さなサムネイルを使用し、ホバー後に保存済みの暗号化アーカイブを読み込んで、履歴プレビュー用の画像を生成します。

- 履歴プレビューは各辺最大720 pxに縮小して扱います。
- プレビューパネルの高さは最大360 ptで、画面の利用可能領域にも収めます。
- 縦長画像でも原寸の高さで画面を覆いません。
- 保存済み画像が取得できない場合は小さなサムネイルへフォールバックします。
- Finderでコピーしたファイル参照は、条件に合うローカル画像ファイルを読み直してプレビューします。原本が利用できなければ保存済みの縮小画像などへフォールバックします。ファイル本体を履歴へバックアップする機能ではありません。
- 選択変更後に遅れて完了した処理を無効化し、前の画像が新しい項目へ表示されることを防ぎます。

画面下に余裕がなければプレビューを上側へ配置するなど、画面内に収めます。画像の読み込み・縮小処理をUIスレッドでまとめて実行しない構成です。

### SVGコード単体

対応するSVG単体のコードは、メニューの文字色に合わせたアイコンプレビューで確認できます。貼り付ける内容は元のSVGコードのままです。ホバー後に上限付きのバックグラウンド処理で描画し、結果をキャッシュします。

外部参照、スクリプト、埋め込み画像、CSS、アニメーションを含むSVGなど、安全に扱える対象外のコードは通常の文章プレビューへ戻します。ブラウザと同じSVG機能をすべて実装するものではありません。

### URL単体

リンクカードは、内容全体がWeb URLとして認識できる場合だけ表示します。先頭・末尾の空白は無視します。

| 内容の例 | 表示 |
| --- | --- |
| `https://company.rev-c.com` | リンクカード |
| `company.rev-c.com` | HTTPSとしてリンクカード |
| `こちらを確認: https://company.rev-c.com` | 通常の文章プレビュー |
| 複数のURLを並べた文章 | 通常の文章プレビュー |
| メールアドレス・`mailto:` | 通常の文章プレビュー |
| 明示的な `http://` URL | リンクカードに警告アイコン |

リンクカードの画像は、サイトが提供するソーシャルプレビュー画像です。ブラウザ画面のスクリーンショットではありません。画像の下にタイトルとURLを表示します。ファビコンはテンプレート名の横に表示します。

**URL単体の項目を含むフォルダの初回表示やホバーでは、macOSのLinkPresentationを通して接続先へアクセスします。** 文章に混在するURLについてはリンク・ファビコン取得を開始しません。

| 取得・キャッシュ | 現在の制限 |
| --- | --- |
| URL長 | 最大2,048文字 |
| 同時取得 | 最大2件 |
| 待機 | 重複を除いて最大32 URL |
| メモリキャッシュ | 最大32件 / おおよそ32 MiB、TTL 24時間 |
| 失敗時の再試行抑制 | 60秒 |
| 画像取得のアプリ側期限 | 8秒 |

再起動するとメモリキャッシュは消えます。画像を取得できない場合もタイトル・URLの表示は維持します。ログインが必要なサイトや、プレビュー画像を提供しないサイトでは画像・ファビコンが表示されないことがあります。

## 設定画面

設定はサイドバー形式です。オン・オフの項目はトグルで操作し、関連する項目を背景と仕切り線でまとめています。

| セクション | 主な設定 |
| --- | --- |
| セットアップ | 「権限ステータス」「クリップボードメニュー」「FasterOCR」の3タブ。権限の確認とショートカット設定。保存済みのキーをキーボード画像で点灯表示（初期値 ⌘⇧V / ⌘⇧2） |
| 一般 | 最大保存数、履歴の保存期限、ログイン時起動、メニューバー表示、ペースト、並び替え、重複履歴、言語 |
| 外観 | システム連動・ライト・ダーク、メニューの色設定 |
| ショートカット | メイン・履歴・テンプレート・履歴消去の割り当てとリセット |
| faster OCR | 有効／無効、ショートカット、認識言語、文章の言語補正、履歴保存 |
| プライバシー | リンクプレビューの取得方法、除外アプリ |
| 権限ステータス | 権限の状態・用途の説明・macOS設定への入口 |
| アップデート | 自動確認、確認間隔、手動確認 |
| 高度な設定 | 上部タブでメニュー・種類・エージェント設定・バグ報告を切り替え |
| Panic（末尾・黄色文字） | 緊急時の履歴・テンプレート・キャッシュ・設定などの削除 |

現在の設定画面に「ベータ」セクションはありません。

設定画面とテンプレートエディタは同じガラス調の背景を使用します。macOS 26ではネイティブのガラス表現、macOS 14–15ではVisual Effectによる背景を使用し、OSの透明度に関するアクセシビリティ設定を尊重します。壁紙のキャプチャや定期スクリーンショットを背景描画に使いません。

## メニューの色をカスタマイズ

「設定 → 外観 → メニューの色をカスタマイズ」で設定します。**メニューの配色を変更できます。プライマリカラーはfaster OCRの選択枠と十字カーソルにも反映されます。設定画面とテンプレート編集画面には適用しません。**

| 色 | 適用先 |
| --- | --- |
| プライマリ・アイコン | 通常時のテンプレート記号などのアイコン |
| テキスト | 通常時のメニュー文字 |
| 背景の色 | メニュー背景への色味 |
| ホバーテキスト | 選択・ホバー時の文字と記号アイコン |
| ホバー背景 | 選択・ホバーした行の背景 |

- 色見本を押してネイティブのカラーパネルを開くか、HEXを直接入力できます。
- HEXは6桁、`#` は省略可能です。有効な値を大文字表記へ統一します。入力途中や不正な値は保存しません。
- ライト・ダークのパレットは別々に保存します。
- 通常背景のカスタム色は固定14%の色味、ホバー背景は85%の不透明度で合成します。透明度を変更する設定ではありません。
- カスタマイズを無効にすると、通常のネイティブ背景を使用します。
- 画像サムネイル、ファビコン、色見本は元の色を維持します。
- 色の変更は次にメニューを開いたときに反映します。
- 「メニューの色をリセット」は両パレットを消去し、カスタマイズを無効にします。

## 保存・削除・プライバシー

### 保存先と暗号化

履歴とテンプレートはMac内に保存します。通常版はユーザーのLibrary内の `Application Support/Revclip`、Demo版は `Application Support/revclip-demo` を使います。設定とキーチェーンの識別も分離します。

| データ | 保護方法 |
| --- | --- |
| 履歴タイトル・テンプレート本文などのDB | SQLCipherによるデータベース全体の暗号化 |
| 保存クリップ・サムネイル | CryptoKitのAES-256-GCMによる暗号化・認証 |
| 鍵 | 256ビットのランダム鍵をmacOSのログインキーチェーンへ保存。DB用・ファイル用はHKDFで分離 |

鍵はiCloud同期の対象にしません。鍵の取得やデータの検証に失敗した場合は収集を止め、既存の暗号化データを新しい鍵や空の履歴で置き換えません。

### 削除の違い

| 操作 | 消えるもの | 残るもの |
| --- | --- | --- |
| メニューの「履歴を消去」 | 履歴のDB行、保存アーカイブ、サムネイル | テンプレート・設定 |
| 最大件数・保存期限による整理 | 条件に該当した履歴のDB行と対応ファイル | それ以外の履歴・テンプレート・設定 |
| Panic | Revclipの履歴・テンプレート・設定・保存鍵・現在のクリップボード | Mac内の無関係なファイル |

手動の履歴消去では、監視を停止し、処理中のコピー保存を待ってから削除し、監視を再開します。整理処理は対象行の選択・削除をDBトランザクション内で行い、その後に対応ファイルを削除します。

自動整理は、連続コピーの最初から約5秒後、起動時、関連設定の変更時、および30分ごとに実行します。後続のコピーで5秒の期限を先送りしません。ファイル削除に失敗した場合はログに記録し、孤立ファイルの整理で再試行できます。

**DBの行は実際に削除します。** `secure_delete`、incremental vacuum、WAL checkpointによる保守も行います。ただし、DBファイルの大きさだけでは残っている履歴件数を判断できません。SSDの物理的な復元不能性や、別途作成されたバックアップの消去を保証しません。

Panicは確認欄へ `Panic` と入力して実行します。削除完了後はアプリを終了します。通常版とDemo版の保存領域は分離されていますが、**現在のクリップボードはmacOS全体で共有**されているため、その消去は他のアプリにも影響します。

### 記録しないデータと保護の限界

- concealed / transient / auto-generatedとしてマークされたコピーは、本文を読む前に除外します。
- 除外アプリに一致した場合も記録しません。ただし判定は監視時の前面アプリに基づくため、コピー直後のアプリ切り替えなどでコピー元と一致しない場合があります。
- 機密マークのないパスワードなどを、内容だけで確実に検出する機能ではありません。
- 保存時の暗号化は、動作中のメモリ、システムのクリップボード、貼り付け先、画面、エクスポートファイルを保護しません。
- 保存鍵を失うと復号できません。鍵の預かり・復旧サービスはありません。
- 旧版の平文データは移行しますが、以前のバックアップやスナップショットまでは変更しません。

詳しくは[セキュリティ方針](SECURITY.md)をご覧ください。実際のコピー内容・鍵・認証情報を公開Issueへ添付しないでください。

### エージェントからの履歴アクセス

Revclip CLIでは、エージェントがテンプレートを作成・編集・削除し、許可された設定を変更できます。明示的な同意付きのバグ報告にも対応します。**履歴一覧・履歴本文・現在のクリップボードを読み出すコマンドはありません。** 保存件数や期限を変更する操作と、保存内容の読み出しは分離しています。バグ報告にも履歴は自動添付しません。

SQLCipherによるDB暗号化、AES-256-GCMによる保存クリップ・サムネイルの暗号化、Keychainでの鍵管理は、保存データを保護する仕組みです。CLIの機能制限と合わせても、同じOSユーザーとして広い操作権限を与えたエージェントや、OS全体を操作できるプログラムを完全に隔離するものではありません。現在のクリップボードは、Revclip CLI以外のmacOS APIやツールから読み取られる可能性があります。動作中のメモリ、画面、貼り付け先、エクスポートやバックアップも、この保存暗号化で一律に保護されるわけではありません。

保存が気になる場合は、メニューの「履歴を消去」を実行できます。Revclip内の履歴のDB行・保存アーカイブ・サムネイルを削除し、テンプレートと設定は残します。件数上限での自動削除も手動消去も、バックアップ・スナップショットやSSD上の痕跡の完全消去を保証しません。「履歴を消去」は現在のmacOSクリップボードを空にする操作ではなく、監視再開後のコピーは設定に従って再び記録されます。詳しくは[セキュリティ方針](SECURITY.md)を参照してください。

## CLIとAIエージェントからの操作

### 現在提供しているもの

配布アプリに同梱するネイティブCLI **`Contents/Helpers/revclip`** から、起動中のアプリのテンプレート・許可された設定を操作し、同意付きのバグ報告を送信できます。アプリの利用・スキル導入・CLI操作にPythonは不要です。通常版・Demo版で同じCLI実装を使用します。

**エージェント用の `revclip` スキルとCLIをアプリ本体に同梱しています。** 「設定 → エージェント設定」でプロンプトをコピーし、CodexまたはClaude Codeへ貼り付けて実行してください。ひとつのエージェントから、このMacで検出した対応ツールのスキル配置先へまとめて登録できます。

1. 同梱インストーラで既存の設定ディレクトリを調査します。
2. 検出した対応ツールへスキルとCLIをコピーします。
3. 再度調査し、登録先・スキップ・競合を報告します。
4. 必要に応じて各エージェントを再読み込みするか、新しいセッションを開きます。

Revclipを起動しただけで登録先へ書き込むことはありません。未検出のツールの設定領域を自動作成せず、管理対象と確認できない同名スキルや、利用者が変更した内容は上書きしません。登録後のテンプレート・設定・バグ報告の操作には、起動中の対象アプリと同じOSユーザーによるローカルCLI実行が必要です。エージェントの権限設定は迂回しません。

「エージェント設定」を開いたときと「再確認」を押したときに、登録状態（`installed`）と更新有無（`update_available`）を調べます。確認だけではインストールや上書きを行いません。更新があればセットアップ用プロンプトをコピーし、エージェントで手動実行します。管理対象の未編集コピーだけを更新し、利用者の変更や競合は報告して停止します。

ターミナルから実行する場合は、`APP` を対象アプリの場所に置き換えます。以下の `path/to/Revclip.app` は相対パスの記入例です。以降のCLI例でも同じ変数を使います。

```sh
APP='path/to/Revclip.app'
"$APP/Contents/Helpers/revclip" agent inspect --app Revclip
"$APP/Contents/Helpers/revclip" agent install --app Revclip
"$APP/Contents/Helpers/revclip" agent inspect --app Revclip
```

製品によって配置先や再読み込み方法が異なります。対応範囲と公式資料は[エージェント導入ガイド](docs/AGENT_SUPPORT.md)を参照してください。モデルのAPIを利用するだけでは、ローカルスキルは読み込まれません。

### 設定もCLIから操作

```sh
"$APP/Contents/Helpers/revclip" --app Revclip settings-schema
"$APP/Contents/Helpers/revclip" --app Revclip settings-get
"$APP/Contents/Helpers/revclip" --app Revclip settings-set --json '{"appearance":"dark","max_history_size":30}'
"$APP/Contents/Helpers/revclip" --app Revclip settings-set --file settings.json
"$APP/Contents/Helpers/revclip" --app Revclip app-action permissions
"$APP/Contents/Helpers/revclip" --app Revclip app-action update-check
```

`settings-schema` に、44項目の設定名・型・範囲と使用可能な操作をまとめています。一般・外観・メニュー・保存形式・除外アプリ・更新設定に加え、OCRの4項目と5種類のショートカットを扱えます。**PanicはGUI専用です。**

```sh
# OCR設定を変更
"$APP/Contents/Helpers/revclip" --app Revclip settings-set --json '{"ocr_language":"ja-en","ocr_save_history":false}'

# OCRのショートカットを確認・既定値へ戻す
"$APP/Contents/Helpers/revclip" --app Revclip settings-get --key shortcut_ocr
"$APP/Contents/Helpers/revclip" --app Revclip settings-set --json '{"shortcut_ocr":{"default":true}}'
```

ショートカットの対象は `shortcut_main`、`shortcut_history`、`shortcut_snippet`、`shortcut_clear_history`、`shortcut_ocr` です。`{}` で解除、`{"default":true}` で既定値へ戻せます。キーコード・修飾キーを指定する書式は[CLIリファレンス](docs/TEMPLATE_CLI.md#preferences-cli-v016)を参照してください。画面取得・OCRの起動・認識結果の読み出しはCLIに公開していません。

変更前にすべての値を検証し、変更後に適用値を返します。保存件数・期限の変更は通常の履歴整理を起動し、追加の削除確認は挟みません。OSの許可やアップデートの完了は、表示される画面でユーザーが操作します。CLIの `queued` は操作の受付を示し、許可・インストール完了を示しません。

CLIからの設定変更は、開いている設定画面の対象コントロールへ反映します。無関係な入力途中の値やバグ報告の下書きは保持します。言語変更時は画面を再生成します。配色の変更がHEX入力中に届いた場合は、次に外観ページを開くまでページ更新を保留します。

### 対象アプリを明示

```sh
# 通常版
"$APP/Contents/Helpers/revclip" --app Revclip folders

# Demo版
"$APP/Contents/Helpers/revclip" --app revclip-demo folders
```

`--app` を省略したネイティブCLIの対象は **通常版のRevclip** です。誤操作を避けるため、例では対象を明示しています。Demo版には `--app revclip-demo` を指定します。テンプレート・設定・バグ報告には起動中の対象アプリが必要です。`agent inspect/install` はローカルのスキル登録を扱い、アプリの起動を必要としません。CLI自体はアプリを起動しません。

### コマンド例

以下の `FOLDER_ID` / `TEMPLATE_ID` は、直前の応答に含まれる `identifier` へ置き換えます。タイトルや数値のDB IDではありません。

```sh
# フォルダを作り、そのidentifierを確認
"$APP/Contents/Helpers/revclip" --app Revclip folder-create --title '作業用'

# 一覧
"$APP/Contents/Helpers/revclip" --app Revclip list --folder FOLDER_ID

# テキストを作成
"$APP/Contents/Helpers/revclip" --app Revclip create --folder FOLDER_ID --title '挨拶' --content 'お世話になっております。'

# UTF-8ファイルから本文を読み込み
"$APP/Contents/Helpers/revclip" --app Revclip create --folder FOLDER_ID --title 'メール' --content-file mail.txt

# 標準入力で本文を更新
printf '%s' '新しい本文' | "$APP/Contents/Helpers/revclip" --app Revclip update TEMPLATE_ID --content-file -

# タイトルだけを更新（本文・画像を維持）
"$APP/Contents/Helpers/revclip" --app Revclip update TEMPLATE_ID --title '新しい名前'

# 埋め込み画像を作成
"$APP/Contents/Helpers/revclip" --app Revclip create --folder FOLDER_ID --title 'ロゴ' --image logo.png

# 非表示に変更
"$APP/Contents/Helpers/revclip" --app Revclip update TEMPLATE_ID --enabled false

# 更新結果を確認
"$APP/Contents/Helpers/revclip" --app Revclip get TEMPLATE_ID
```

削除が必要な場合のみ、次の操作を使用します。フォルダは空でなければ削除できません。

```sh
"$APP/Contents/Helpers/revclip" --app Revclip delete TEMPLATE_ID
"$APP/Contents/Helpers/revclip" --app Revclip folder-delete EMPTY_FOLDER_ID
```

### 応答・編集の整合性

- 応答はJSONで、`ok` と `result` または `error` を返します。失敗時の終了コードは1です。
- ローカルソケットを通してアプリへ依頼し、アプリの暗号化ストレージを使用します。CLIがDBを直接書き換える構成ではありません。
- 開いているエディタの下書きを保存してから要求を処理し、変更後はエディタ・メニューを更新します。
- タイトルだけの更新では本文・画像を維持します。本文を明示すると画像からテキストへ、画像を指定するとテキストから画像へ置き換えます。
- 一覧・取得応答には画像本体を含めません。`media_bytes` で画像テンプレートを識別できます。
- タイムアウトした書き込みも完了している可能性があります。再試行前に一覧・取得で確認してください。
- ソケットへのアクセスは同じOSユーザーに制限します。同じユーザーで動く他のプログラムから隔離する仕組みではありません。

詳細は[テンプレートCLI](docs/TEMPLATE_CLI.md)を参照してください。

## 通常版とDemo版

機能を別々に実装していません。**同一ソース・同一の起動処理・設定・エディタ・クリップボードサービス・CLIから、配布用メタデータを変えて生成します。**

| 項目 | 通常版 | Demo版 |
| --- | --- | --- |
| アプリ名 | `Revclip.app` | `revclip-demo.app` |
| Bundle ID | `com.revclip.Revclip` | `com.revclip.revclip-demo` |
| データ領域名 | `Revclip` | `revclip-demo` |
| 更新フィード | 公開版の署名付きフィード | 未設定 |
| 署名 | 配布用Developer ID | ローカル開発用ID |
| 機能実装 | 共通 | 共通 |

設定、テンプレート、ログイン登録、macOSの権限は分離されるため、同じソースでも登録内容や見た目の設定は異なることがあります。Demo版のデータを通常版へ自動コピーする処理ではありません。

`scripts/check_demo_parity.py` で、製品ソースにDemo専用マクロやBundle名による機能分岐が入っていないかを検査します。ただし、すでにインストールした古いアプリが自動で同じビルドになるわけではありません。反映確認には両アプリのバージョン・ビルド番号も確認します。

詳しくは[配布構成](docs/DISTRIBUTIONS.md)を参照してください。

- XcodeGen

```sh
open src/Revclip/build/Debug/Revclip.app
```

**通常のDebugビルドは、インストール済み通常版と同じアプリID・データを使用します。** 既存のRevclipを終了してから起動してください。データを分離して開発・撮影する場合はDemo版を使用します。

ソース内の `scripts/revclip` と `agents/AgentSupport/install.py` はPython版の開発・互換検証用です。利用者向けの導入手順ではなく、ネイティブCLIの代わりにPythonの導入を求めるものではありません。

### テストと編集

```sh
make -C src/Revclip test
python3 scripts/check_demo_parity.py
open src/Revclip/Revclip.xcodeproj
```

プロジェクトの正本は `src/Revclip/project.yml` です。構成を変更した場合は `make -C src/Revclip setup` でXcodeプロジェクトを再生成します。

### Demo版

```sh
make -C src/Revclip demo-run
```

DemoビルドはUniversal構成で、既定で `Apple Development` の署名IDを使用します。この署名に使えるローカル証明書が必要です。通常版を終了してからDemo版へ切り替え、意図せず両方でコピーを監視しないようにしてください。

### 配布ビルド

公開配布には、Releaseビルドに加えて署名、公証、DMG作成、署名付き更新フィードの生成が必要です。ローカルビルド成功だけを公開版の検証完了とは扱いません。実行手順・必要な認証設定は[リリース手順](docs/RELEASING.md)を参照してください。

### 負荷を抑える仕組み

- クリップボードの変更カウントを確認し、変更がなければ内容を読みません。
- メニュー表示用サムネイルと、ホバー時の大きなプレビューを分離します。
- ホバー待ち時間内に項目から離れた場合、履歴プレビュー用アーカイブの読み込みを省きます。
- 履歴プレビューのキャッシュは128件・おおよそ32 MiBに制限します。
- URL取得には同時実行数・待機数・キャッシュ・期限を設けます。

保存サイズ・キャッシュ上限は、アプリ全体のピークメモリ使用量を保証する値ではありません。競合製品とのCPU・メモリ比較値は公開していません。過去の改善と測定条件は[性能メモ](docs/PERFORMANCE.md)に記録しています。

CIはWoodpeckerでCLI・配信検証・フィードバック機能などの共通テストを実行し、GitHub ActionsのmacOS環境でXcodeテストとUniversalビルドを確認します。署名・公証・公開の担当範囲は[リリース手順](docs/RELEASING.md)に記載しています。

## 困ったとき

### アプリからバグ報告

「設定 → バグ報告」で件名と再現手順を入力し、「送信元情報の取得に同意します。」をチェックして送信します。連絡先は任意です。送信元情報はIP・地域・回線・言語・タイムゾーン・アプリ／OSバージョン・User-Agentです。未同意では送信できません。

Cloudflare経由で開発者のTelegramグループに届きます。履歴・テンプレート・クリップボード・ログ・スクリーンショットは自動添付しません。送信失敗時は入力を残します。通信がタイムアウトした場合、既に届いている可能性があるため、自動再送は行いません。

CLIでも送信できます。次のオプションは送信元情報の取得・送信への明示的な同意を表します。

```sh
"$APP/Contents/Helpers/revclip" --app Revclip bug-report --title '問題の概要' --description-file report.txt --consent-source-info
```

Botのトークンはアプリに含めず、サーバーのSecretで管理します。[送信処理と運用](docs/FEEDBACK_DEPLOYMENT.md)、[セキュリティ方針](SECURITY.md)も参照してください。

| 症状 | 確認すること |
| --- | --- |
| メニューは開くが自動で貼り付かない | Revclipのアクセシビリティ許可と「ペーストコマンド」を確認。手動の⌘Vでも復元内容を確認 |
| コピーした内容が記録されない | 保存対象の種類、除外アプリ、コピー元の機密マークを確認。鍵・DBの初期化失敗時も収集しません |
| URLの画像・ファビコンが出ない | URL単体か、サイトが画像を提供するか、ネットワークへ接続できるかを確認。失敗後は60秒の抑制があります |
| プロンプト内のURLがリンクカードにならない | 意図した動作です。文章に含まれるURLは通常の文章として扱います |
| 縦長画像が原寸で表示されない | プレビューは画面内に収まるよう縮小します。保存内容そのものをプレビュー寸法に置き換える仕様ではありません |
| CLIが接続できない | 対象アプリが起動中か、`--app Revclip` / `--app revclip-demo` が正しいかを確認 |
| CLIの更新がタイムアウトした | `get` / `list` で現状を確認してから再試行 |
| 色設定が反映されない | カスタマイズの有効状態とライト・ダークの対象を確認し、メニューを開き直す |
| 設定画面の色が変わらない | メニュー専用の色設定です。設定画面・エディタには適用しません |
| ガラス表現が画像と違う | macOSのバージョン、外観、透明度のアクセシビリティ設定によって見え方が変わります |
| 履歴を消したのにDBファイルが大きい | ファイルサイズと残存行数は別です。DB保守やWALの状態によってサイズは即座に縮まらない場合があります |
| Demoと通常版で内容が異なる | データと設定は分離されています。両アプリのバージョン・ビルド番号も確認 |

不具合報告には、アプリのバージョン、macOSのバージョン、通常版かDemo版か、再現手順を添えてください。必要なら機密情報を除いたスクリーンショットを添付してください。
