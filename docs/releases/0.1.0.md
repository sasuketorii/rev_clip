# Revclip 0.1.0

- Media templates with thumbnails, bounded image hover previews and portable
  embedded image data.
- URL-only link previews, favicons and HTTP warnings; mixed prose and email
  addresses retain text previews.
- Template CLI for create, update, delete and folder management.
- Wrapped menu titles and screen-bounded popup placement.
- HTML clipboard preservation, including design payloads embedded in markup.
- Atomic history retention and manual-clear capture synchronization.
- Isolated demo build for recording without mixing normal user data.
- AGPL-3.0-only for v0.1.0 onward; existing MIT and third-party notices retained.

Build number: 33. Template database schema: 3.
No private demo templates or clipboard data are included in this release.
