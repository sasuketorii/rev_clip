# プレビューで内容を確かめ、Finderのファイル参照と原本を区別する

Revclipは履歴の項目にポインタを合わせると、文章・画像・対応するSVG・URL単体をプレビューします。プレビューは内容を確かめるための表示です。Finderでコピーした項目は、ファイル本体ではなく、そのときのファイル参照です。サムネイルは原本の代わりになりません。

<!-- block: callout tone=warning -->
> **受入状況:** このページはRevclip 0.1.9（build 42）のソースと既存資料を照合して作成しています。実際のFinderプレビュー、ファイルのコピー、実アプリへの貼り付けを組み合わせた受入確認は完了していません。

## 履歴メニューを開き、項目にポインタを合わせる

1. **⌘⇧V**でメインメニューを開きます。履歴だけを開く場合は**⌘⌃V**を使うか、メニューバーのRevclipアイコンをクリックします。
2. 内容を確認したい履歴の行にポインタを合わせます。対応する項目では、少し待つとプレビューパネルが表示されます。フォルダ行ではなく、履歴項目の行を選んでください。
3. 表示された内容と行のタイトルを見てから、使う項目を決めます。履歴の行を選ぶと、その内容をクリップボードへ戻します。自動ペーストが有効なら元のアプリへ貼り付け、無効なら貼り付け先で**⌘V**を押します。

### プレビューできる内容と表示上の制限

<!-- block: dataTable -->
| 項目 | プレビューに表示するもの | 制限・注意点 |
| --- | --- | --- |
| 文章 | コピーされた文字列 | 長文はプレビュー内で約2,000字まで表示し、残りを省略します。省略表示はプレビューだけの制限です。 |
| HTML・RTF・RTFD・PDF | 行のタイトルや、クリップボードが提供した文字列 | PDFや書式付き文書をページ全体として描画するビューアではありません。貼り付け時に使われる形式と、プレビュー表示は別です。 |
| 画像 | 行の小さなサムネイルと、ホバー時の縮小画像 | 履歴プレビューの画像は各辺最大720 px、パネルの高さは最大360 ptです。 |
| Finderのファイル参照 | ファイル名。参照先が条件を満たす画像なら画像プレビュー | プレビューできるのは最初のファイルだけです。ファイル本体を履歴へバックアップする機能ではありません。 |
| 単体のSVGコード | メニューの文字色に合わせた図形・アイコン | `<svg`から始まる単体コードが対象です。入力は128 KiBまで、要素数512まで、入れ子32段まで、パスデータ64 KiBまでです。 |
| 単体のWeb URL | サイト提供の画像、タイトル、URL | サイトへ接続して情報を取得します。最大2,048文字で、画像がなくてもタイトルとURLは残ります。 |

SVGプレビューは、対応する図形を限られた範囲でアイコン表示します。次の要素を含むSVGは通常の文章表示に戻ります。

- スクリプト、CSS
- 外部リソースへの参照、埋め込み画像
- アニメーション、`<defs>`、`<text>`

XML宣言やMarkdownのコード囲みが付いたテキストも単体SVGとして扱いません。どの場合も、履歴から戻す文字列はコピー時のSVGコードです。

<!-- block: callout tone=warning -->
> **URLのプレビューは通信します。** 開発版の既定は手動取得です。リンクにカーソルを合わせて⌥Pを押すと、macOSのLinkPresentationを通じてサイトに接続します。IPアドレスやURL全体が伝わり得るため、機密URLは取得しないでください。「プライバシー → リンク」で自動取得・取得しないへ変更できます。文章の途中に書かれたURLや複数URLの文章はリンクカードにならず、URL取得も開始しません。

URLカードの画像は、サイトが提供するソーシャルプレビュー画像です。Webページのスクリーンショットではありません。画像がなくてもタイトルとURLは表示します。自動取得を選んだ場合は、URLテンプレートのフォルダ表示時や履歴URLのホバー時にも取得します。手動取得ではこれらの操作だけで通信しません。

同時取得は最大2件です。重複を除いて最大32 URLを待機させます。成功結果は最大32件・約32 MiBのメモリーキャッシュに24時間保持します。失敗後は60秒間、同じURLの再取得を抑えます。画像取得のアプリ側期限は8秒です。再起動するとキャッシュは消えます。

`http://`で始まるURLには警告アイコンが付きます。スキームのない単体ドメインはHTTPSとして扱います。メールアドレス、`mailto:`、本文に混在したURL、複数URLを含む文章はリンクカードの対象外です。

## Finderでコピーした項目はファイル本体ではなく参照として戻る

Finderでファイルをコピーすると、クリップボードにはファイル名やファイルURLの参照が渡されます。Revclipが履歴へ記録するのもこの参照です。元ファイルそのものは履歴に保存しません。履歴の行を選ぶと、記録した参照がクリップボードへ戻ります。

画像プレビューを作る際は、参照先を読み込めるか確認します。Revclipは取り込み時に縮小画像を保存し、履歴行をホバーしたときも元の参照先を読み込めるか試します。ファイル本体を履歴用に複製する処理ではありません。

画像プレビューには条件があります。参照先がローカルの通常ファイルで、その場で読み込める必要があります。未ダウンロードのiCloud項目やネットワーク上の場所は対象外です。読み込めるのは10 MiB以下の静止画像で、各辺は8,192 px以下、合計は1,600万画素以下です。複数ファイルをコピーした場合、画像プレビューは先頭の項目だけです。

画像のサムネイルが残ることはあります。原本を移動・削除した後でも、保存済みの縮小画像だけは表示される場合があります。履歴の参照先は自動で更新されません。移動先のファイルを使うには、Finderで新しい場所から改めてコピーしてください。削除済みなら、元の保管場所から先に戻します。

### ファイル参照を確認して使う

1. Finderで対象ファイルを選び、**⌘C**でコピーします。
2. Revclipの履歴メニューを開き、追加された行のファイル名を確認します。画像ファイルなら、行にポインタを合わせてプレビューも確認します。
3. その参照を使うときは、貼り付け先アプリを確認してから履歴行を選びます。自動ペーストが無効なら、貼り付け先で**⌘V**を押します。
4. ファイルを後から移動した場合は、移動先のファイルをFinderで再度コピーします。古い履歴のサムネイルが表示されても、古い参照先が新しい場所へ自動更新されたことを意味しません。

## 選択した項目とプレビューの内容を照らし合わせる

プレビューは履歴の項目を見分けるための表示です。文章は長いと省略表示され、SVGは図形として描画され、画像は縮小されます。どの場合も表示用の加工を、貼り付けデータそのものの編集と混同しないでください。

Finder項目では、プレビュー画像が残っているかどうかと、ファイル参照が現在も有効かどうかを別に確かめます。ファイルが移動・削除されて参照先が使えなければ、残っているサムネイルを見られても原本を貼り付けられるとは限りません。また、貼り付け結果はコピー元アプリが提供した形式と貼り付け先アプリが受け付ける形式にも左右されます。

## プレビューが出ないときは項目の形式と参照先を確かめる

| 症状 | 確認すること |
| --- | --- |
| 文章のプレビューが出ない | フォルダではなく履歴の行をホバーしているか確認します。設定のメニュー項目でツールチップ表示が無効になっていないかも確認してください。 |
| 画像やFinder画像のプレビューが出ない | 画像がローカルで利用可能か、静止画像か、サイズが10 MiB以下か、画素数が上限内かを確認します。クラウドの未ダウンロード項目は、先にFinderでダウンロードしてください。 |
| 移動・削除したファイルのサムネイルだけが残る | サムネイルは画像確認用です。ファイル参照は自動で追従しないため、現在の場所からファイルをコピーし直します。 |
| URLカードに画像が出ない | 項目全体が単体URLか確認します。ログインが必要なサイトや、プレビュー画像を提供しないサイトでは画像が出ないことがあります。通信に失敗してもタイトルとURLは表示されます。 |
| SVGがコードのまま表示される | コードが単体SVGか確認します。XML宣言、Markdownのコード囲み、説明文、対応外のSVG機能が含まれる場合は通常の文章表示に戻ります。 |
| コピーした履歴行そのものがない | Revclipのクリップボード監視は既定で500ms間隔です。次の観測までに別のコピーで上書きされた内容を回収できる保証はありません。コピー履歴の説明も確認してください。 |

プレビュー設定の詳細は[設定を調整する](07-settings.md)を参照してください。履歴に記録する形式と、選択後の貼り付け方法は[履歴を探して貼り付ける](04-history-and-paste.md)で確認できます。
