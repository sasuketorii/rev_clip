# Revclip ドキュメント

Revclipは、Macでコピーした内容を履歴から再利用し、繰り返し使う文章や画像をテンプレートにまとめる道具です。エージェントにはテンプレートの作成・編集・削除を任せられます。

まずは、コピーしてから履歴を開き、別の場所へ貼り付ける操作を試してください。その後、毎回使う文章をテンプレートにすると、必要な内容を呼び出しやすくなります。

## 履歴とテンプレートの違い

**履歴**は、コピーした内容の一時的な保存先です。保存件数や期限に応じて整理されます。**テンプレート**は、繰り返し使いたい内容を自分で登録して管理するものです。履歴を消す操作と、テンプレートを消す操作は別です。

<!-- block: callout tone=info -->
> RevclipのCLIには、コピー履歴や現在のクリップボードを読むコマンドがありません。CLIの`list`や`get`が対象にするのはテンプレートです。ただし、同じMac上の別のプログラムからの画面操作やOS機能まで隔離する仕組みではありません。[保護範囲と限界](10-privacy-and-security.md)を確認してください。

## このガイドの対象

このガイドはRevclip 0.1.9を対象にしています。通常版とDemo版ではデータ・設定が分かれています。操作中のアプリ名とバージョンを確認し、CLIでは対象を明示してください。

コピー元や貼り付け先が対応する形式、macOSの権限、コピーの速さによって結果が変わることがあります。期待どおりに動かないときは、履歴や設定を初期化する前に[症状別の確認手順](11-troubleshooting.md)を参照してください。
