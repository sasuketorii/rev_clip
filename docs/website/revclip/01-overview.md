# コピー履歴とテンプレートをMacで使い分ける

RevclipはmacOSのメニューバーから開くクリップボードマネージャーです。最近コピーした内容を履歴から選び直したり、繰り返し使う文章や画像をテンプレートとして保存したりできます。

## 履歴は最近のコピー、テンプレートは繰り返し使う内容

履歴はコピーした内容を一時的に保管する場所です。テンプレートは、定型文やプロンプトなどを自分で登録して使う機能です。履歴を消去してもテンプレートは削除されません。

<!-- block: dataTable -->
| 機能 | 使い方 | 保存の考え方 |
| --- | --- | --- |
| コピー履歴 | コピーした項目を後から選び、クリップボードへ戻します。設定した形式だけを記録します。 | 件数や保存期限の設定に応じて整理されます。 |
| テンプレート | 繰り返し使う文章や画像を登録し、メニューから呼び出します。 | 履歴とは別に管理します。 |
| プレビュー | メニューの項目にポインタを合わせ、内容を確認します。 | プレビューの種類によって表示できる内容が異なります。 |

## 対応環境とネットワーク利用を確認する

このガイドは公開版Revclip 0.1.9（build 42）を対象にしています。対応OSはmacOS 14以降です。配布DMGはApple SiliconとIntelの両方に対応するUniversalアプリです。

履歴とテンプレートはMac内に保存され、クラウド同期はありません。アカウント登録も不要です。更新の確認・ダウンロード、URLだけの項目のプレビュー取得、同意して送る不具合報告ではネットワークを使います。

自動ペーストにはmacOSのアクセシビリティ許可が必要です。許可しない場合も、履歴項目を選んで内容をクリップボードへ戻し、貼り付け先で⌘Vを押す方法を使えます。

<!-- block: callout tone=warning -->
> **0.1.9の確認範囲:** 公開版のCI、署名・公証、更新配信は確認されています。一方、コピー直後の実際の描画、貼り付け、連続操作を使った実機受入は完了していません。監視の既定間隔は500msで、次の観測より前に上書きされたコピーをすべて記録する保証はありません。

## エージェント連携はテンプレートと許可された設定が対象

同梱のネイティブCLIとエージェント用スキルを使うと、テンプレートの作成・編集・削除と許可された設定の読み書きを依頼できます。CLIのコマンドにコピー履歴や現在のクリップボードを取得する機能はありません。CLIの制限は、同じmacOSユーザーで動く別のプログラムやOS機能からのアクセスを完全に隔離するものではありません。

## 現行アプリはAGPL-3.0-onlyで提供する

現行アプリのライセンスはAGPL-3.0-onlyです。MITライセンスの表示は旧コードや依存ライブラリに関するもので、現行アプリ全体をMITとして提供している意味ではありません。
