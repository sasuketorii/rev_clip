# 履歴からコピー内容を選び直す

コピー履歴は、対応するクリップボード形式をMac内に保存し、後から選べるようにします。履歴項目を選ぶと内容がクリップボードへ戻ります。自動ペーストを使うかどうかは設定とmacOSのアクセシビリティ許可で変わります。

## 記録する形式を「設定 → 種類」で選ぶ

Revclipは、コピー元がクリップボードへ提供したデータのうち、保存対象にした形式を履歴へ記録します。同じコピーが複数形式を持つ場合があります。

<!-- block: dataTable -->
| 形式 | 保存される内容 |
| --- | --- |
| プレーンテキスト | 書式のない文章やコード |
| リッチテキスト（RTF／RTFD） | 書式付きテキスト。RTFDは添付を含む場合があります。 |
| HTML | コピー元が提供した書式や構造情報 |
| PDF | クリップボードへ提供されたPDFデータ |
| ファイル名 | コピーされたファイルへの参照。ファイル本体のバックアップではありません。 |
| URL | クリップボード上のURL形式 |
| 画像（TIFF） | クリップボードへ提供された画像データ |

「設定 → 種類」で形式ごとの保存を切り替えます。コピー元がその形式を提供していない場合や、保存対象をすべてオフにした場合は履歴に残らないことがあります。コピー元・貼り付け先アプリが独自に使う形式や遅延提供データは、すべて復元できるとは限りません。

除外アプリに登録したアプリからのコピーは保存しません。コピー元がconcealed（機密）、transient（一時的）、auto-generated（自動生成）のマークを付けた内容も、内容を読み込む前に除外します。除外アプリの判定は観測時に前面にあるアプリに基づくため、コピー直後のアプリ切り替えなどでコピー元と一致しない場合があります。

## 履歴項目を選び、貼り付け先へ戻す

1. 元アプリで使いたい内容をコピーします。
2. ⌘⇧Vで履歴とテンプレートのメインメニューを開くか、⌘⌃Vで履歴メニューを開きます。メニューバーのRevclipアイコンからも開けます。
3. 必要なら項目にポインタを合わせて内容をプレビューし、使う履歴の行を選びます。
4. 自動ペーストを使うときは、選択した内容がクリップボードへ復元された後、Revclipがメニューを開いた時点のアプリへ⌘Vを送ります。
5. 自動ペーストを使わないときは、貼り付け先へ戻り、⌘Vを押します。

「設定 → 一般」の「ペーストコマンド」をオフにすると、自動で⌘Vを送らず、選択した内容をクリップボードへ戻す動作になります。アクセシビリティ許可がない場合も、手動で⌘Vを押して貼り付けられます。

選択した内容が貼り付け先に入れば完了です。自動ペーストが有効でも、対象アプリの状態や受け付ける形式によっては貼り付けを確認できない場合があります。その場合は、同じ項目を選んだ後に貼り付け先で⌘Vを押してください。

<!-- block: callout tone=warning -->
> コピー監視の既定間隔は500msです。これはコピーから画面表示までの上限時間ではありません。観測までに別のコピーでクリップボードが上書きされると、前の内容が履歴に残らないことがあります。0.1.9の実機での描画、貼り付け、連続操作の受入も未完了です。

## 保存件数と並び順を調整する

履歴の保存上限は既定で30件です。メニューに一度に表示する件数とは別の設定で、既定では10件ずつサブメニューにまとめます。「設定 → 一般」で最大保存数や保存期限を調整できます。上限を超えた履歴は整理対象になりますが、整理は非同期のためコピー直後に一時的に設定数を超えることがあります。

同じ内容を再コピーしたとき、または履歴から選び直したときに、その項目を先頭へ動かすかは「同一履歴を上書き」と「ペースト後に並び替え」で決まります。

<!-- block: dataTable -->
| 同一履歴を上書き | ペースト後に並び替え | 外部で同じ内容を再コピー | 履歴から選んで復元 |
| --- | --- | --- | --- |
| オフ | オフ | 並び順を維持 | 並び順を維持 |
| オン | オフ | 最新位置へ移動 | 並び順を維持 |
| オフ | オン | 並び順を維持 | 最新位置へ移動 |
| オン | オン | 最新位置へ移動 | 最新位置へ移動 |

「ペースト後に並び替え」がオンの場合、履歴から選んだ項目の利用順は、クリップボードへの復元が成功した時点で更新されます。自動ペーストがオフでも対象です。復元後に対象変更などでキー送信が取り消されても、復元成功は取り消しません。復元書き込みが失敗した場合は更新しません。テンプレートの利用は、この履歴項目の並び替えとは別です。

## 困ったとき

<!-- block: dataTable -->
| 状況 | 確認すること |
| --- | --- |
| コピーした行が見つからない | 「設定 → 種類」の保存対象、除外アプリ、500msの観測前に上書きされていないかを確認します。短いテスト文章を1つだけコピーして試します。 |
| 選択後に貼り付けられない | 「設定 → 一般」の「ペーストコマンド」とアクセシビリティ許可を確認します。手動の場合は貼り付け先で⌘Vを押します。 |
| 文字以外の形式が正しく復元されない | コピー元と貼り付け先が同じ形式を提供・受理するか確認します。アプリ固有形式や外部リソースの再現は保証されません。 |
| 履歴の順番が変わった | 「同一履歴を上書き」と「ペースト後に並び替え」の組み合わせを確認します。 |

CLIに履歴一覧や本文を取得するコマンドはありません。履歴を見るときはRevclipのメニューを使います。
